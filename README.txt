# Кластеризация муниципалитетов России: иерархическая модель L1 → L2 на KAN-энкодере

Иерархическая динамическая кластеризация **2 022 муниципальных образований (МО) 
России** за **2019–2024 годы** на атрибутированной сети с **KAN-энкодером** 
(Kolmogorov–Arnold Network), **внешней валидацией через СберИндекс** и 
**post-hoc оценкой ICVI** (SW, CH, DB, S_DbW, AVI, AVU, MQ).

---

## Задача

Выявление **устойчивых типов локальных экономик**, которые не сводятся 
к стандартному делению «регион — центр / периферия». На уровне L1 модель 
находит грубое urban/rural-разделение, на уровне L2 — внутреннюю 
дифференциацию внутри каждого класса.

---

**FEATS (10 признаков для KAN-L1):** `log_pop`, `rel_pop_region`, 
`urban_share`, `invest_pc`, `housing_pc`, `built_pc`, `bad_roads`, 
`msu_exp_pc`, `salary`, `retail_pc`.

**EXTRA_PROFILE (2 признака для интерпретации):** `migr_rate`, 
`tax_share`. Они не подаются в KAN, не участвуют в кластеризации, 
но используются:
- в профилях L1/L2 (mean по кластеру);
- в Kruskal-Wallis и pairwise тестах;
- в median split MWU (сравнение «высокие» vs «низкие» годы СберИндекса).

Причина такого разделения:
- **`tax_share`** исключён из FEATS паспортизацией как вырожденный: 
  63 из 66 МО с `tax_share = 100` — московские внутригородские образования, 
  признак не различает кластеры. Но в интерпретации он полезен: 
  показывает «фискально автономные» МО.
- **`migr_rate`** исключён из FEATS из-за высокой корреляции с `salary` 
  и `invest_pc` (мультиколлинеарность искажает KAN-энкодер), но 
  информативен для описания миграционных типов МО.
- **`natural_rate`** не построен: файл `Y48112004` отсутствует в 
  публичной выгрузке БД ПМО на Kaggle — единственный из 11 показателей, 
  который не удалось получить.


**Период 2019–2024 (6 годовых срезов)** выбран по двум причинам:

1. **Покрытие признаков.** Период 2019–2024 
   полностью покрывается всеми 11 показателями.
2. **Оптимизация KAN.** Горизонт 6 лет × 2 022 МО = 12 132 наблюдения — 
   достаточный объём для обучения KAN-энкодера без переобучения. 
   Увеличение горизонта до 2010–2024 (15 лет) дало бы 30 000+ наблюдений, 
   но потребовало бы жёсткой импутации для ранних лет, что исказило бы 
   структуру. 2025 год исключён из-за неполных данных.

### СберИндекс

Источник: [**sberindex.ru/ru/dashboards**](https://sberindex.ru/ru/dashboards/). 
**4 национальных ряда** загружены независимо от Росстата:

| Ряд | Что содержит | Период |
|---|---|---|
| **Медианные зарплаты** (`median_wages`) | 19 отраслевых рядов медианной зарплаты | 2020–2026 |
| **Потребительская активность** (`consumer_activity`) | 5 возрастных групп, индекс потребительской активности | 2021–2026 |
| **Инфляция** (`inflation`) | Текущий темп недельной инфляции | 2012–2026 |
| **Реальная ключевая ставка** (`real_key_rate`) | Ключевая, реальная ставка, базовая инфляция | 2013–2026 |

**СберИндекс используется только для внешней валидации**, не участвует 
в KAN, не входит в признаки узлов, не влияет на выбор K/subK. Это 
методологическое решение: если SberIndex попадает в признаки кластеризации, 
его корреляция с кластерами становится тавтологией, а не независимой 
проверкой.

## Методология

### Пайплайн

Росстат (11 XLSX)  +  Справочник ОКТМО
         │
         │  → 8 показателей → FEATS (10 признаков)
         │  → 2 показателя  → EXTRA_PROFILE (профили/валидация)
         │  → 1 показатель  → исключён (нет данных)
         ↓
Препроцессинг: паспортизация → отбор признаков → winsorization → 
                импутация → z-стандартизация (per-year)
         ↓
KAN-энкодер L1 (10 → 32 → 8) + whitening
↓
Mutual kNN-граф (k=10) → выбор K по устойчивости →
KMeans(K=2) → L1-метки (urban / rural)
↓
KAN-энкодер L2 (per parent, 10 → 16/32 → 6/8) + whitening
↓
Выбор subK по устойчивости → L2-метки (K0.S0, K0.S1, K1.S0, K1.S1, K1.S2)
↓
Динамика (ARI, changepoints) + внешняя валидация (тип МО, СберИндекс, jackknife)
↓
ICVI post-hoc (SW, CH, DB, S_DbW, AVI, AVU, MQ)



### Ключевые методологические решения

**1. KAN-энкодер, а не MLP или PCA.**
Исходный проект использовал KAN 36→32→16 с R² = 0.9936. KAN сохраняет
**воспроизводимость** проекта и даёт R² = 0.985 
на пуле 12 132 наблюдений × 10 признаков. KAN реализован полностью 
самодостаточно (B-сплайны Кокса-де Бура + SiLU-ветвь), без сторонних 
KAN-библиотек.

**2. Выбор K по устойчивости, а не по композитному ICVI.**
Аудит показал, что композитный ICVI при вырожденных признаках даёт 
монотонную зависимость от K и не является критерием выбора. 
В данной версии K выбирается по трём независимым критериям:
- **Bootstrap-ARI** (40 итераций, 80 % МО) ≥ 0.75
- **Silhouette-sweep** ≥ 0.15
- **Jackknife по регионам** ≥ 0.85

Для L1: K* = 2 (bootstrap 0.896, silhouette 0.687, jackknife 1.000).

**3. Иерархия L1 → L2.**
L1 находит грубое urban/rural-деление. L2 ищет внутреннюю 
дифференциацию **независимо для каждого родителя**: свой KAN-энкодер, 
свой K-selection, свои ICVI. Для urban subK = 2, для rural subK = 3. 
Итого 5 L2-подкластеров.

**4. SberIndex — только для валидации.**
4 национальных ряда используются:
- для Spearman/Pearson корреляций с prevalence кластеров;
- для median split MWU — сравнения профилей МО в «высокие» и «низкие» 
  годы по каждому показателю Сбера (154 значимых сдвига из 280, FDR < 0.05);
- для сопоставления роста зарплат L1/L2 с отраслевыми рядами Сбера.

**5. ICVI post-hoc.**
7 метрик (SW, CH, DB, S_DbW, AVI, AVU, MQ) посчитаны **после** фиксации 
K/subK по stability-метрикам. Это осознанный компромисс: закрывает 
требование конкурса, не создаёт зависимости от противоречивого критерия. 
Для L1 честно зафиксировано: AVI = 0.286, MQ = 0.063 — **следствие 
imbalance 57/1965**, а не слабость модели. На сбалансированной подвыборке 
(57 urban + 57 rural) AVI = 0.743, MQ = 0.451.

## Результаты

### L1 (urban / rural)

| Метрика | Значение |
|---|---|
| K | 2 |
| Размеры кластеров | 57 urban / 1 965 rural |
| ARI(consec) между годами | 0.977 |
| Stay rate | 0.999 |
| Changepoints (ARI < 0.8) | 0 |
| Silhouette | 0.687 |
| AVI | 0.286 (сбалансированная: 0.743) |
| MQ | 0.063 (сбалансированная: 0.451) |
| Chi² vs тип МО | 992.4, p = 1.6e-213 |
| Jackknife urban | 1.000 |
| Jackknife rural | 0.223 (следствие дисбаланса 57/1965) |
| Без Москвы/МО ARI | 0.110 |

### L2 (подкластеры внутри родителей)

| Подкластер | subK | Размер | Silhouette | ARI(consec) |
|---|---|---|---|---|
| K0 (urban) | 2 | 339 набл. | 0.269 | 0.616 |
| K1 (rural) | 3 | 11 793 набл. | 0.222 | 0.627 |

**Содержательная интерпретация:** K1.S2 (n = 162) — регионально-специфичный 
подкластер (Московская область, top-1 = 12.3 %), при удалении которого 
jackknife = 0.063. Это подкластер агломерации, а не универсальный тип МО.

### Внешняя валидация через СберИндекс

- 154 значимых сдвига профилей (median split MWU) из 280 тестов, 
  FDR < 0.05. Топ-сдвиги: `bad_roads` (urban-МО в «высокие» годы по 
  зарплатам имеют на 15.95 п.п. меньше плохих дорог), 
  `rel_pop_region`, `invest_pc`.
- Spearman корреляции prevalence × SberIndex не проходят FDR при N = 4..5 
  лет — честно зафиксировано в отчёте.

## Воспроизведение

Весь цикл выполняется в **Kaggle Notebook (CPU-only, без GPU)**. 
Требования: Python 3.13, стандартное окружение Kaggle (numpy, pandas, 
scikit-learn, scipy, matplotlib, plotly, pyarrow, torch — все предустановлены).

**Пошагово:**

1. Открыть `notebooks/sber_cluster_fin.ipynb` в Kaggle.
2. **Add Input → Datasets** → подключить `masiliobrazilio/cluster-data` 
   (Росстат + СберИндекс).
3. **Add Input → Datasets** → подключить `cluster-mo-russia-v2-artifacts` 
   (промежуточные артефакты, опционально).
4. **Run All → Save & Run All (Commit)**.
5. Дождаться завершения (~1500 сек на CPU).
6. В Output появится `save/clustering_v2_artifacts.zip` (~115 MB, 
   118+ файлов).

**Просмотр результата без перезапуска:**

- Открыть `processed/viz/index.html` в браузере — интерактивный лендинг 
  со всеми графиками и слайдерами.
- Читать `processed/reports/report_for_llm.md` — машиночитаемый отчёт 
  с разделами L1, L2, SberIndex, ICVI, ограничениями.

## Честные ограничения

1. **Jackknife L1 K1 = 0.223** при удалении Свердловской области (67 МО, 
   3.4 % класса). Следствие дисбаланса 57/1965: при пересчёте KMeans(2) 
   на 1 898 МО границы urban/rural сдвигаются. На urban-кластере 
   jackknife = 1.000.
2. **L1 без Москвы/МО ARI = 0.110** — метки переворачиваются при 
   переналожении разбиения. Для K = 2 при отсутствии Москвы в urban-классе 
   это ожидаемо. Основной критерий для L1 — silhouette = 0.687 и 
   stability-метрики.
3. **K1.S2 (n = 162)** — регионально-специфичный подкластер (Московская 
   область). Это подкластер агломерации, а не универсальный тип МО.
4. **SberIndex-корреляции с N = 4..5 лет** статистически слабы: ни одна 
   не проходит FDR. Устойчивый сигнал даёт только median split MWU.
5. **Годовые данные Росстата** — нет внутригодовой динамики; СберИндекс 
   на национальном уровне с 2020/2021 — перехлёст только по 5 последним 
   годам.
6. **`tax_share` исключён** паспортизацией как вырожденный (63 из 66 МО 
   = Москва). Отсутствие этого признака сужает интерпретацию фискальной 
   автономии.
7. **Муниципальные датасеты СберИндекса** («потребительские траты по 
   категориям», «покупательская мобильность») требуют ручной выгрузки 
   с дашбордов; использованы только национальные ряды.
