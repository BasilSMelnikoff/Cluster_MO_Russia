# Воспроизведение проекта

Инструкция для воспроизведения полного цикла кластеризации 
муниципалитетов России (L1 + L2) с нуля в Kaggle Notebook.

**Время прогона:** ~1500 сек на CPU (без GPU).
**Требования:** Kaggle Notebook (бесплатный аккаунт), все данные — через Add Input.

---

## 1. Что понадобится

### 1.1. Окружение

- **Платформа:** Kaggle Notebook
- **Язык:** Python 3.13 (стандартное окружение Kaggle)
- **Железо:** CPU-only (проект не требует GPU)
- **Интернет:** не требуется, если данные подключены через Add Input
- **Всего времени:** ~1500 сек на чистый прогон всех 13 ячеек

Библиотеки: `numpy`, `pandas`, `pyarrow`, 
`scikit-learn`, `scipy`, `torch`, `matplotlib`, `plotly`, `openpyxl`. 
Полный список — в `requirements.txt`.

### 1.2. Датасеты для подключения

Через **Add Input → Datasets** подключить датасет:

| Датасет | Что содержит | Обязателен |
|---|---|---|
| `masiliobrazilio/cluster-data` | 11 XLSX Росстата + 4 parquet СберИндекса |

### 1.3. Файлы в репозитории

- `notebooks/sber_clustering_v2.ipynb` — основной ноутбук (13 ячеек)
- `configs/preprocessing_config.json` — гиперпараметры (уже сформирован)
- `requirements.txt` — список зависимостей
- `docs/REPRODUCIBILITY.txt` — этот файл

## 2. Пошаговый запуск

### Шаг 1. Открыть ноутбук в Kaggle

1. Зайти на [kaggle.com](https://www.kaggle.com/) → **Code** → 
   **New Notebook**.
2. **File → Import Notebook** → загрузить `sber_cluster_fin.ipynb` 
   из локальной копии репозитория.
3. Убедиться, что включено **Accelerator: None (CPU)** — GPU не нужен.

### Шаг 2. Подключить датасеты

1. В правой панели ноутбука → **Add Input**.
2. Найти `masiliobrazilio/cluster-data` → **Add**.


### Шаг 3. Запустить прогон

1. Верхнее меню → **Run All**.
2. Дождаться завершения всех 13 ячеек (~1500 сек).
3. Проверить, что в консоли последней ячейки появилась строка:
[XXXX.Xs] отчёт + PDF + ZIP готовы

---

## 3. Что должно получиться

### 3.1. Ключевые метрики

После полного прогона в консоли ячейки 12 отображаются:

L1: K = 2
L2: subK = {0: 2, 1: 3}, всего 5 подкластеров
МО: 2022, лет: 6 (2019–2024)
Признаков: 10

ARI L1(consec): 0.9767, stay rate: 0.9988
L2 K0: ARI=0.6157, stay=0.9000
L2 K1: ARI=0.6268, stay=0.8665


**Если числа заметно отличаются** (например, K = 3 вместо K = 2, 
или ARI < 0.9) — это означает одно из двух:
- версия `scikit-learn` в Kaggle обновилась и KMeans дал другое 
  разбиение (фиксируется через `random_state=42`, но обновления 
  версий могут слегка менять результат).

### 3.2. Проверка консистентности

В конце прогона в консоли отображается:

ИТОГО ПРОВЕРОК: OK=XXX, FAIL=0


Если `FAIL > 0` — открыть соответствующую ячейку, найти строку с 
`[FAIL]`, и разобраться. Все проверки в коде самодокументируемые.

Если полный прогон не нужен — можно посмотреть готовые артефакты:

### 4.1. Методологический отчёт

1. Открыть `processed/reports/methodology_report_ru.pdf` в любом PDF-просмотрщике.
2. Разделы: Executive summary, L1, L2, SberIndex, ICVI, ограничения.

### 4.2. Машиночитаемый отчёт

1. Открыть `processed/reports/report_for_llm.md` в любом текстовом редакторе.
2. Тот же отчёт в Markdown — можно передать в LLM для авто-интерпретации.
